GameLearn uses a standardized control scheme across all its titles so you can pick up any game and feel right at home from the very first second. Whether you're on a desktop with a keyboard and mouse, tapping away on your phone, or using a gamepad, the core inputs stay consistent — letting you focus on strategy and fun instead of hunting for buttons.

<Tabs>
  <Tab title="Keyboard & Mouse">
    Most GameLearn titles support keyboard-first play with intuitive shortcuts that feel natural the moment you start. Here's the standard mapping used across the library:

    | Key / Input        | Action                          |
    | ------------------ | ------------------------------- |
    | Arrow Keys         | Move / Navigate                 |
    | Space              | Action / Jump                   |
    | Escape             | Pause / Open Menu               |
    | Enter              | Confirm / Select                |
    | Z                  | Secondary Action 1              |
    | X                  | Secondary Action 2              |
    | Mouse Click        | Interact / Select               |
    | Mouse Scroll       | Zoom In / Out (where supported) |

    Mouse inputs work alongside keyboard controls in most titles, especially in puzzle and strategy games where clicking to interact is the primary way to play.
  </Tab>
  <Tab title="Mobile Touch">
    GameLearn's mobile experience is built for smooth touch play. Every game that runs on desktop also runs on your phone or tablet with adapted touch controls. Here's how gestures map to actions:

    - **Tap** — interact with objects, select menu options, or trigger the primary action
    - **Swipe Left / Right / Up / Down** — move your character or navigate in the corresponding direction
    - **Double Tap** — trigger jump or a quick secondary action in supported games
    - **Press and Hold** — charge an action, hold a button input, or open a context menu
    - **Pinch to Zoom** — zoom the game view in or out where the game supports it (common in strategy titles)
    - **Two-Finger Swipe** — scroll or pan the game camera in map-based games

    On-screen button overlays appear automatically in action and arcade games so you always have quick access to key inputs without memorizing gestures.
  </Tab>
  <Tab title="Controller">
    GameLearn supports standard USB and Bluetooth gamepads, including Xbox-style and PlayStation-style controllers. Plug in or pair your controller and it's recognized automatically — no extra setup needed. The standard button layout looks like this:

    - **D-Pad** — move / navigate menus
    - **A Button (Xbox) / Cross (PS)** — confirm / primary action / jump
    - **B Button (Xbox) / Circle (PS)** — cancel / secondary action
    - **X Button (Xbox) / Square (PS)** — secondary action 2 / interact
    - **Y Button (Xbox) / Triangle (PS)** — context action (varies by game)
    - **Left Stick** — move character or pan camera
    - **Right Stick** — rotate camera or aim (where supported)
    - **Start / Options** — pause the game / open the menu
    - **Left Bumper / Right Bumper** — cycle through tabs or use special abilities

    Controller support is available across all game genres. If your specific controller isn't detected, try remapping it through your browser or OS settings before launching.
  </Tab>
</Tabs>

## Game-Specific Controls

While the standard controls above apply to most GameLearn titles, every game also ships with its own detailed control guide tailored to its unique mechanics. When you launch any game, the loading screen displays a full breakdown of every input and what it does in that specific title. You can also access the in-game control guide at any time by pausing and opening the **Help** tab in the pause menu.

Don't stress about memorizing everything upfront — the in-game guide is always one pause away.

<Tip>
  You can remap almost any control to your preferred keys or buttons right from the **Settings** menu in your GameLearn profile. Head to Settings → Controls to customize your layout and save your preferences so they apply every time you play.
</Tip>
